# Установка MyHuyauncher

Пакет: `ru.example.myhuyauncher`.

Файл сборки:

`\MyHuyauncher\app\build\outputs\apk\debug\app-debug.apk`

На головном устройстве должен быть включён ADB. Ноутбук подключается кабелем с передачей данных. В командах ниже при нескольких устройствах добавляйте серийник: `adb -s <serial> ...`.

## Разрешения

| Разрешение | Как выдаётся | Зачем |
|---|---|---|
| Поверх других окон (`SYSTEM_ALERT_WINDOW`) | Вручную, команда ниже | Без него кнопки на экране не будет |
| Список всех приложений (`QUERY_ALL_PACKAGES`) | При установке, команда ниже на случай если не выдалось | Чтобы в сетке были приложения |
| Автозапуск после включения (`RECEIVE_BOOT_COMPLETED`) | При установке, команда ниже на случай если не выдалось | Кнопка появляется после запуска планшета |
| Фоновая служба (`FOREGROUND_SERVICE`) | При установке, команда ниже на случай если не выдалось | Чтобы кнопка не пропадала |

Выдать всё одной пачкой после установки:

```bat
adb shell appops set ru.example.myhuyauncher SYSTEM_ALERT_WINDOW allow
adb shell pm grant ru.example.myhuyauncher android.permission.QUERY_ALL_PACKAGES
adb shell pm grant ru.example.myhuyauncher android.permission.RECEIVE_BOOT_COMPLETED
adb shell pm grant ru.example.myhuyauncher android.permission.FOREGROUND_SERVICE
```

Проверить:

```bat
adb shell appops get ru.example.myhuyauncher SYSTEM_ALERT_WINDOW
adb shell dumpsys package ru.example.myhuyauncher
```

У «поверх других окон» в ответе должно быть `allow`. У трёх остальных в блоке разрешений пакета должно быть `granted=true`. Если `pm grant` отвечает, что разрешение нельзя менять, оно уже выдано при установке.

Потом один раз открыть приложение. Пока его ни разу не запускали, автозапуск после включения планшета не сработает.

```bat
adb shell am start -n ru.example.myhuyauncher/.MainActivity
```

Если система показывает экран разрешения, на планшете нажать **Разрешить**. Та же выдача с компьютера:

```bat
adb shell appops set ru.example.myhuyauncher SYSTEM_ALERT_WINDOW allow
adb shell am start -n ru.example.myhuyauncher/.MainActivity
```

## Установка

Обычный Android, если `adb install` проходит:

```bat
adb install -r "\MyHuyauncher\app\build\outputs\apk\debug\app-debug.apk"
```

Сразу после этого выполнить команды разрешений из раздела выше и запустить приложение.

Geely / Volga на user-прошивке, где `adb install` отвечает `User build type restriction prevents installing`. Так было на Volga K40. Команда `pm install` там закрыта. Пакет ставится установщиком из `GeelyCityray-AppInstaller-main`: APK кладётся в папку `apks` рядом с `install.bat`, затем запускается `install.bat`. После этого снова команды разрешений и ручной запуск.

На этой прошивке замена поверх уже стоящей версии не применяется. Старый пакет удаляют и ставят заново. `adb uninstall` на Volga зависает, а `adb shell` с текстом `uninstall` сразу закрывается. Удаление делают скриптом.

Файл `rm-pkg.sh` (перевод строки LF, одна строка):

```sh
pm uninstall ru.example.myhuyauncher
```

```bat
adb push rm-pkg.sh /data/local/tmp/rm-pkg.sh
adb shell sh /data/local/tmp/rm-pkg.sh
adb shell rm /data/local/tmp/rm-pkg.sh
adb shell pm path ru.example.myhuyauncher
```

Успех удаления — строка `Success`. `pm path` после этого ничего не печатает. Затем установка заново и снова выдача разрешений: после удаления «поверх других окон» сбрасывается.

## Как проверить

Справа внизу появляется полупрозрачная кнопка 40×40. По нажатию открывается сетка своих приложений, системные лежат под **Остальные приложения**. **Скрыть** убирает кнопку до следующего ручного запуска MyHuyauncher.
